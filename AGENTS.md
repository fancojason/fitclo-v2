# Product detail pages

- When a product's fabric is given as Nylon / Spandex, show the same percentages with both English fiber names in visible Fabric fields: `Nylon / Spandex (Polyamide / Elastane)`. For example, `70% Nylon / 30% Spandex (70% Polyamide / 30% Elastane)`. Do this even when the source provides only Nylon / Spandex; these are alternate names for the same fibers, not additional ingredients. Never infer missing percentages.
- Follow [the product detail image layout](docs/product-detail-image-layout.md) for gallery and detail image order.
