# Product detail image layout

For future product detail pages, use the supplier's product listing and detail images as the first source. Verify that each image belongs to the correct style before publishing.

- Main gallery: product cover first, product feature image second, matching-series or available-combinations image third when supplied, followed by the site's two standard service images. A matching-series image may show related styles; label it as a series image and do not describe every pictured item as part of the selected SKU.
- Product Details: use a three-column, two-row layout. The first row shows attractive, distinctive model views of the product, preferably two front colorways and a single-model back view. A combined front/back image is acceptable when a suitable single-model back image is unavailable.
- The second row shows the color chart, construction/detail image, and fabric image, in that order. Search the supplier's detail images for these before using substitutes. If one type is genuinely unavailable, use another verified image of the same product and describe it accurately.
- Display detail images at their natural proportions with the whole image visible. Do not use fixed-height crops or magnification that cuts off the garment, color chart, construction details, or fabric image.
